# v1.1.5 数字区间识别检查

问题样例为 `[-45.67%, 19.38%]`。在 Windows 原生 Paddle Inference 和缓存的 `PP-FormulaNet_plus-S` 上，原始图片能稳定复现 `[left- 4 5.6 7 \` 的输出。

## 定位与修复

检查预测 token 后确认：模型在第一个百分号处提前生成结束标记，右端点尚未生成，截断发生在 LaTeX 清理和 MathML 转换之前。同一模型单独识别两个端点时可以读出数字及百分号。

- 对疑似不完整的纯数字区间，检查图片中的独立括号、单个逗号和单行布局，再复用当前预测器识别两个端点。最多增加两次预测，普通公式沿用原来的处理路径。
- 端点必须是数字、小数、正负号及可选百分号，已有数字和百分号必须与初次结果一致，可见字符数量也必须匹配。缩放后的较高端点先归一化高度，避免窄数字被重复读取。
- 括号来自图片中的可确认形状；多逗号、换行、边界不清楚、字符粘连或结果冲突时保留初次结果。区间仍疑似不完整时，界面提示核对或切换模型，下一次正常结果会清除旧提示。
- 只对独立数字及完整的纯数字区间合并 OCR 分散的数字，并将百分号写为 `\%`。文本、上下标、分数、矩阵及其他通用 LaTeX 保留原有语义。

## 回归样例

真实模型对比使用相同的本地模型文件、CPU 运行时及预测器。原版对照关闭新增的区间恢复和纯数字清理。

| 样例 | 修复前 | 修复后 |
| --- | --- | --- |
| 用户截图中的 `[-45.67%, 19.38%]` | 第一个百分号处截断，右端点缺失 | `[-45.67\%, 19.38\%]` |
| 原图缩小至 75%、放大至 150%、四周增加留白 | 截断；早期恢复实现还曾重复右端点的首位数字 | 最终实现均得到 `[-45.67\%, 19.38\%]` |
| `[-12.5%, 8.25%]` | 第一个百分号处截断 | `[-12.5\%, 8.25\%]` |
| `(-12.5%, 8.25%)` | 第一个百分号处截断 | `(-12.5\%, 8.25\%)` |
| `[-45.67, 19.38]` | 左括号命令残缺，数字分散 | `[-45.67, 19.38]` |
| 独立的 `45.67%` | `4 5.6 7 \%`，MathML 拆成多个数字节点 | `45.67\%` |
| 普通等式及已有双行分段公式 | 用作回归对照 | 输出保持一致 |

`(-3.5%, +2.75%]` 的单独右端点仍可能被该模型读成 `+pm2.75\%`。该结果不满足数字端点条件，恢复会放弃并提示核对。这组样例用于验证本次修复及保守退出行为，不代表模型的通用识别准确率。

测试图片放在 `formula_ocr_app/testdata/`，包括只保留公式的原始问题截图，以及生成的开区间、无逗号小数和三个数值样例。

## 检查结果

- 四个 unittest 模块合计 152 项，150 项通过、2 项环境依赖测试跳过。覆盖缩放、小屏幕可达性、复制反馈、数字拆分、误读保护、保留原结果及不完整提示。
- 52 项 Word/MathML 回归通过，百分比区间的两个数字、两个百分号和两端括号均保留在 Word 兼容格式中。
- Python 静态检查（Ruff `E4,E7,E9,F`）及 `git diff --check` 通过。
- 桌面自检在检查键盘输入前主动激活测试窗口，避免 PowerShell 后台启动时将系统焦点条件误判为编辑器失败；仍检查焦点转移、真实按键、撤销重做和剪贴板。
- 打包后的运行环境、UI、52 项 Word/MathML 和浏览器预览自检通过；原图与放大图通过目录版 EXE 的真实模型识别，输出均为 `[-45.67\%, 19.38\%]`。
- 打包版原生 Win32 剪贴板自检通过，确认 HTML/MathML 和 Unicode 纯文本内容；百分比区间也单独通过浏览器预览自检。
- 安装包及 SHA-256 校验文件由 `build_installer.ps1` 生成；安装包同时附带本轮界面和识别检查记录，README 中的相对文档链接可以访问。

在已缓存 `PP-FormulaNet_plus-S` 的源码环境中，可以复现问题样例：

```powershell
python -m formula_ocr_app.app --self-test --self-test-model PP-FormulaNet_plus-S --self-test-image formula_ocr_app/testdata/percent_interval.png
```

预期输出为 `[-45.67\%, 19.38\%]`。
