# v1.1.3 界面与交互检查

本轮范围为界面布局与操作反馈，起点是 v1.1.2 的按钮文字遮挡和复制成功提示不明显。

这些界面改动与后续数字区间识别修复一起纳入 v1.1.4 公开发布；以下保留 v1.1.3 本地验证记录。

## 修复

| 问题 | 处理 |
| --- | --- |
| Windows 缩放后，“复制 MathML”“编辑 LaTeX”等按钮裁字 | 共享按钮同时按 DPI 和实际字体测量计算最小尺寸；绘制使用控件实际分配的宽高，并在尺寸变化时重绘 |
| 标题、说明和操作按钮在窄窗口互相挤压 | 共用的工具栏按可用宽度换行，标题与操作区在空间不足时分行；长状态和模型说明随窗口宽度换行 |
| 复制成功只出现在左下角状态栏 | 在操作附近显示约 2.4 秒的提示，覆盖 LaTeX、编辑区选中文本及更多格式；重复操作重置提示计时，不抢走编辑焦点 |
| 成功、空内容和 Word 富格式降级容易混淆 | 提示在实际写入剪贴板后出现；无内容和纯文本降级使用不同提示；复制失败清除上一条成功提示并报告错误 |
| 模型管理在大字体或小窗口下遮挡内容 | 操作按钮、快捷筛选支持换行，表格行高与列宽适配缩放并提供横向滚动；详情改为可选择复制、可滚动的只读文本区 |
| 模型下拉框键盘选项移出可见范围 | 下拉框适配缩放，方向键、Home/End 同步滚动到当前焦点；按钮和选项显示键盘焦点，禁用按钮跳过 Tab 导航 |
| 滚动条的默认 Canvas 高度意外撑大详情区 | 滚动条只申请必要的宽度，由父容器决定高度 |
| 空公式点击刷新仍显示“正在刷新”，手动刷新后继续编辑可能留下过期状态 | 区分空内容、转换失败和预览完成；预览任务追踪最新编辑内容，完成消息保留后续复制操作的反馈 |

## 验证

- 原生 Windows Python 3.10 / Tk 环境，以 96 DPI 为基准分别设置 100%、125%、150%、175%、200% 的 Tk 缩放，检查初始窗口、最小窗口、恢复窗口后的按钮文字与祖先容器边界。
- 新增 11 项 UI 回归测试，涵盖缩放布局、实际剪贴板文本、选区复制、焦点保留、提示超时与替换、失败和降级提示、空预览、刷新时编辑、模型详情及键盘滚动；已接入 CI。
- 四个 unittest 模块合计 139 项：137 项通过、2 项环境依赖测试跳过。预览任务状态的追加修复单独重新验证通过。
- Python 静态检查（Ruff `E4,E7,E9,F`）和 `git diff --check` 通过。
- 最终目录版的运行环境、UI、50 项 Word/MathML 和浏览器预览自检通过；`--clipboard-self-test --require-native-clipboard` 确认原生 Win32 剪贴板中的 HTML/MathML 与纯文本内容正确。安装包 SHA-256 与随附校验文件一致。

本地安装包由 `build_installer.ps1` 生成，目录版由该脚本调用 `build_exe.ps1` 构建。

```text
dist/FormulaOCR/FormulaOCR.exe
dist/installer/FormulaOCRSetup-1.1.3.exe
dist/installer/FormulaOCRSetup-1.1.3.exe.sha256
```
